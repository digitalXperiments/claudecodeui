## Fixes applied (2026-09-25, source only, not yet built)

| Workstream | Summary | Kill switch |
|---|---|---|
| A1 server infra | gzip `compression` middleware (skips SSE / pre-gzipped); `/assets/*` skips `public/`; auth runs once per request plus a 30 s user cache; SQLite pragmas (WAL, synchronous=NORMAL, mmap, cache, busy_timeout); relay sync and Mission Control boot work moved after `listen` | — |
| A2 data paths | `/api/projects` DB-only (`?sync=1` or the sidebar refresh button forces a rescan) with one shared in-flight sync; per-project progress broadcast removed; native FSEvents watcher with per-file coalescing; incremental JSONL history parsing; title lookups read only new bytes; run events sent to the client before being saved, saves batched every 50 ms; `run_event` sent only to subscribers | `CLOUDCLI_WATCHER_POLLING=1`, `CLOUDCLI_PERF_BATCH_RUN_EVENTS=0` |
| B warm sessions | Claude process kept warm between turns (10 min TTL, max 4, evicted when options change); **live token streaming** (`includePartialMessages`); Keychain, MCP config, resume-model and model-catalog lookups cached | `CLOUDCLI_WARM_CLAUDE_SESSIONS=0`, `CLOUDCLI_CLAUDE_WARM_TTL_MS`, `CLOUDCLI_CLAUDE_WARM_MAX`, `CLOUDCLI_CLAUDE_STREAM_PARTIAL=0` |
| C launch path | Startup JS/CSS 1,097 → 461 KB gz: xterm/CodeMirror/KaTeX/Prism off the startup path, non-English locales lazy, self-hosted fonts, inline static shell, parallel auth bootstrap, service worker registered once with a capped cache | — |
| D chat render | Per-session store subscriptions; composer isolated (typing no longer re-renders the transcript); memoized rows; no per-render reflow; collapsibles mount on open; Myers diff; incremental streaming split with a plain preview of unclosed fences; provider auth checks deferred to the model picker (**cause of the 1.5 s session-open delay**); history-first layout effect; 50-row first page; hover prefetch; one shared sidebar minute clock | — |

Verification before rebuild: client tsc and server tsc clean; client tests 286/286; store tests 49/49; server tests 1224/1235, and the 10 failures also fail on a clean HEAD or come from separate in-progress `session_run_errors` work (no migration yet). ESLint: 0 new errors. The scratch `vite build` succeeds, and a headless browser check against the live backend showed no page errors.

## Rebuild steps

```
launchctl bootout gui/$(id -u)/com.claudecodeui.server
# optional but recommended: raise the libuv pool (must be set outside the process)
/usr/libexec/PlistBuddy -c "Add :EnvironmentVariables:UV_THREADPOOL_SIZE string 16" ~/Library/LaunchAgents/com.claudecodeui.server.plist
npm install          # new deps: compression, @fontsource/encode-sans, @fontsource/merriweather (already in node_modules)
npm run build
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.claudecodeui.server.plist
tail -f ~/Library/Logs/claude-code-ui/stderr.log   # confirm there is no crash-loop
```
