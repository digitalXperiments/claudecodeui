# CloudCLI Command Center Prototype

Standalone clickable HTML prototype for the proposed workspace-first CloudCLI experience.

Open `index.html` directly in a browser, or serve the repository root with any static server and visit `/prototype/`.

Included dummy-data surfaces:

- Command Center dashboard
- Workspace list and workspace detail
- Chat, diff review, checks, terminal, and files tabs
- Activity / Run Observatory
- Review queue
- Agent Swarm
- Kanban
- Projects
- Studio
- Needs You
- Settings and onboarding
- Responsive mobile layout, theme toggle, command palette-style modal, filters, toasts, and stateful demo actions
